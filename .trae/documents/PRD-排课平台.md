# 排课平台产品需求文档

## 1. 产品概述

智能排课管理系统，为教育机构提供高效的课程安排解决方案。通过可视化的课程体系管理和智能排课算法，帮助学校和培训机构简化排课流程，提升教学资源利用率。

### 核心价值
- 简化复杂的排课流程，减少人工排课的时间和错误
- 支持设置课程每周课节数，实现精细化的排课频率控制
- 通过轮流和随机算法实现公平、均衡的课程分配
- 提供直观的可视化展示，方便教师和学生快速了解课程安排
- 支持 Docker 容器化部署，持续集成到腾讯云 TKE

## 2. 核心功能

### 2.1 用户角色
本系统为单用户版本，主要用户为教务管理人员或校长。

### 2.2 功能模块
1. **首页/仪表盘**: 展示排课概览、数据统计、快速入口
2. **课程体系管理**: 维护课程类别、课程信息
3. **教师管理**: 维护教师基本信息、教授课程
4. **智能排课**: 根据规则自动生成课程表
5. **课程表展示**: 列表视图和日历视图展示排课结果

## 3. 核心流程

### 3.1 课程管理流程
```
新增课程 → 填写课程信息（名称、类别、时长）→ 保存课程 → 课程列表展示
```

### 3.2 教师管理流程
```
新增教师 → 填写教师信息（姓名、教授课程）→ 保存教师 → 教师列表展示
```

### 3.3 排课流程
```
选择排课规则（轮流/随机） → 设置排课参数（时间段、教室、每周课节数） → 执行排课算法 → 生成课程表（含自由活动）
```

### 3.4 排课算法说明
- **轮流排课**: 按照课程和教师的顺序，依次分配到不同的时间段，保证公平性。按周轮询分配课节，不超过课程设置的每周课节数上限。
- **随机排课**: 通过随机算法将课程和教师分配到时间段，增加多样性。同样受每周课节数限制。
- **自由活动机制**: 当所有课程已达到每周课节数上限时，自动填充"自由活动"时间。自由活动在课程表中以绿色高亮显示。

## 4. 用户界面设计

### 4.1 设计风格
- **设计理念**: 现代简洁、专业高效，采用卡片式布局
- **主色调**: 深蓝色 (#1a365d) 配合橙色强调色 (#ed8936)
- **辅助色**: 浅灰色背景 (#f7fafc)，白色卡片 (#ffffff)
- **字体**: 思源黑体 (Noto Sans SC) 用于中文，Roboto 用于英文
- **图标**: 使用 Lucide Icons，线条简洁
- **布局**: 左侧导航栏 + 右侧内容区，卡片式信息展示

### 4.2 页面设计

#### 4.2.1 仪表盘首页
| 模块 | 设计描述 |
|------|---------|
| 统计卡片 | 显示课程总数、教师总数、本周排课数、排课完成率 |
| 快捷操作 | 四个主要功能入口按钮（课程管理、教师管理、智能排课、查看课表） |
| 最近排课 | 展示最近生成的课程安排列表 |

#### 4.2.2 课程体系管理页
| 模块 | 设计描述 |
|------|---------|
| 课程分类侧边栏 | 树形结构展示课程分类（语文、数学、英语等） |
| 课程列表 | 卡片式展示课程信息，包含课程名称、时长、每周课节数、状态 |
| 新增/编辑弹窗 | 表单形式填写课程详细信息，含每周课节数设置（1-10节） |

#### 4.2.3 教师管理页
| 模块 | 设计描述 |
|------|---------|
| 教师列表 | 网格布局展示教师卡片（头像、姓名、教授课程数） |
| 教师详情 | 点击展开显示教授课程详情 |
| 新增/编辑弹窗 | 表单形式编辑教师信息 |

#### 4.2.4 智能排课页
| 模块 | 设计描述 |
|------|---------|
| 排课规则选择 | 切换按钮选择"轮流排课"或"随机排课" |
| 参数设置区 | 时间段选择器、课程勾选、教师分配 |
| 排课预览 | 实时预览排课结果表格 |
| 执行排课按钮 | 触发排课算法生成课程表 |

#### 4.2.5 课程表展示页
| 模块 | 设计描述 |
|------|---------|
| 视图切换 | 切换按钮选择"列表视图"或"日历视图" |
| 列表视图 | 表格形式展示所有课程安排（时间、课程、教师、教室） |
| 日历视图 | 网格日历形式，可按日/周/月查看，拖拽调整课程 |
| 筛选功能 | 按课程、教师、日期筛选显示 |

### 4.3 响应式设计
- **桌面端**: 1200px以上，完整三栏布局
- **平板端**: 768px-1199px，收缩侧边栏
- **移动端**: 768px以下，底部导航，汉堡菜单

### 4.4 交互细节
- 所有列表支持搜索和筛选
- 新增/编辑操作使用模态弹窗
- 删除操作需要二次确认
- 操作成功/失败使用 Toast 提示
- 加载状态使用骨架屏或 Loading 动画
- 表单验证实时反馈

## 5. 数据结构

### 5.1 课程数据
```
课程ID、课程名称、所属分类、默认教室、课程时长、每周课节数、状态、创建时间
```

### 5.2 教师数据
```
教师ID、姓名、头像、电话、邮箱、教授课程列表、创建时间
```

### 5.3 排课结果数据
```
排课ID、课程ID、章节ID、节序号、教师ID、时间段ID、教室ID、日期、状态、创建时间
```

### 5.4 时间段定义
```
时间段ID、星期几、开始时间、结束时间
```

### 5.5 自由活动
```
使用特殊课程ID（__free_activity__）标记自由活动时间，在课程表中以绿色高亮显示
```

## 6. 技术栈选择理由

- **React 18**: 组件化开发，状态管理方便，生态丰富
- **Tailwind CSS**: 原子化CSS，快速构建响应式界面
- **Vite**: 开发体验好，构建速度快
- **Zustand**: 轻量级状态管理，比 Context API 性能更优
- **Dexie.js**: IndexedDB 封装，支持持久化存储
- **Lucide React**: 图标库轻量且美观
- **Docker + Nginx**: 容器化部署，SPA 路由重写
- **GitHub Actions + TKE**: 持续集成/持续部署
