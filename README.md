# 排课平台

智能排课管理系统，为教育机构提供高效的课程安排解决方案。

## 功能特性

### 1. 课程体系管理
- 维护课程分类（语文、数学、英语等）
- 管理课程信息（名称、时长、状态）
- 分类筛选和搜索功能

### 2. 教师管理
- 维护教师基本信息
- 关联教师教授的课程
- 教师信息搜索和筛选

### 3. 智能排课
- **轮流排课**: 按顺序依次分配，保证公平性
- **随机排课**: 随机分配，增加多样性
- 可设置排课周期（1-4周）
- 实时预览排课结果
- 选择要排课的课程、教师、时间段和教室

### 4. 课程表展示
- **列表视图**: 表格形式展示所有课程安排
- **日历视图**: 周视图，可按周切换查看
- 按课程、教师筛选
- 关键词搜索

## 技术栈

- **React 18**: UI框架
- **TypeScript**: 类型安全
- **Vite 5**: 构建工具
- **Tailwind CSS 3**: 样式方案
- **React Router DOM 6**: 路由管理
- **Zustand**: 状态管理
- **Lucide React**: 图标库
- **date-fns**: 日期处理
- **LocalStorage**: 数据持久化
